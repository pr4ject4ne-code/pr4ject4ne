- **Neon cold-start auto-recovery shipped (45711b5, pushed).** Root problem, hit AGAIN this session while opening pages for a visual pass: Neon free-tier auto-suspends when idle, and the first query after a quiet spell throws `Connection terminated due to connection timeout` / `Connection terminated unexpectedly` → the API 500s → the page renders empty ("No hospitals/entries found") until a manual reload. This is the recurring symptom behind several past "app looks broken" moments (and the memory'd "restart the preview server to clear the poisoned pool" workaround). **Fixed properly in `src/lib/db.ts`** instead of by manual reloads:
  - `withDbRetry()` wraps `query()` and `withTransaction()`: catches ONLY transient connection errors (`isTransientConnectionError` matches connection-terminated/timeout/terminating/ECONNRESET/ETIMEDOUT/ENOTFOUND/57P01/57P03) and retries with exponential backoff (~300/600/1200ms, 4 attempts, ~2.1s worst case). Real SQL/constraint errors are never retried (surface immediately). `withTransaction` retries the WHOLE tx on a fresh client (a failed tx rolled back, nothing committed) — callbacks there must stay DB-only for this to be safe.
  - Added `pool.on('error', …)` handler: evicts dead idle clients (the actual fix for the "poisoned pool keeps 500ing after a blip" state — no more manual server restart) and prevents an errored idle client from crashing the process as an uncaughtException.
  - Tests: `src/lib/__tests__/db-retry.test.ts` (4, mocks `pg`) — retry-then-succeed, no-retry-on-SQL-error, gives-up-after-4, pool-error-handler-registered. **250 tests / 31 suites green** (one transient dev-tertiary timeout flake under concurrent background load, clean on isolated re-run — the known flake, not a regression), type-check + lint clean.
  - Couldn't catch a live cold-*error* to watch the retry fire on demand — Neon kept waking within the 5s connectionTimeoutMillis each attempt (any prior activity warms it), so live curls just returned slow 200s. Mechanism is proven by unit tests; live app healthy.
