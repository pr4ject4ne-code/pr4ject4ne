## Content
- Core concepts: cardinality, one-to-one correspondence, Aleph-Null (countable infinity, natural numbers), the Continuum (uncountable infinity, real numbers).
- Cantor's diagonal argument: list decimals, build a new number differing in every digit, contradiction → reals are uncountable, so "uncountable infinity is larger than countable infinity."
- The Continuum Hypothesis: whether an intermediate infinity exists between integers and reals; "can neither be proved nor disproved using standard set theory axioms."
